## 2026-09-29 - Added Tooltips for Better Discoverability
**Learning:** Users might not know what complex features like 'Group Similar Series' or 'Focus Mode' do without hovering over them. Adding tooltips to these elements significantly improves discoverability without cluttering the UI.
**Action:** Use the new `ToolTip` class in `widgets.py` to add tooltips to complex features that require explanation.
