## 2024-05-23 - Tkinter Global Cursor Configuration
**Learning:** In Tkinter, setting the cursor property via `ttk.Style().configure` (e.g., `cursor='hand2'`) on widgets like `TButton` is silently ignored because cursor is a widget-level option, not a style option. To apply pointer cursors globally without manually configuring every widget instance, you must use the Tk option database (`root.option_add`). Furthermore, you must only apply cursors to specific interactive leaf widgets (e.g., `*TButton.cursor`, `*TCheckbutton.cursor`). Applying a global cursor to container widgets (like `*TNotebook.cursor`) causes a severe UX regression where the entire application page incorrectly displays a hand cursor, as child widgets inherit the cursor if not overridden. Finally, macOS requires the `pointinghand` cursor name, while Linux/Windows use `hand2`. Unconditionally using `pointinghand` on Linux crashes Tkinter with a `_tkinter.TclError: bad cursor spec`.
**Action:** Always conditionally configure cursors based on `platform.system()` and use `root.option_add` specifically targeting only leaf interactive components.
