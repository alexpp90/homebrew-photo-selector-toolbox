## 2024-05-24 - Tkinter Cursor Bug on Hover
**Learning:** Setting the cursor property directly on `ttk.Button` instances using `ttk.Style().configure('TButton', cursor='hand2')` is silently ignored by Tkinter because cursor is a widget-level option, not a style option. Using `root.option_add('*TButton.cursor', 'hand2')` works globally but on Linux using `pointinghand` causes a `_tkinter.TclError: bad cursor spec`. For global cursors on macOS use `pointinghand`, for others use `hand2`. It's better to configure this via `root.option_add` rather than individually to ensure all current and future buttons have consistent hover states.
**Action:** Apply cursor globally using `root.option_add` for `*TButton.cursor`, `*TCheckbutton.cursor`, `*TRadiobutton.cursor` in `apply_dark_theme()` while strictly checking `platform.system() == "Darwin"` to prevent crashes on Linux/Windows.
