## 2026-10-07 - Added Tooltips to Focus Mode
**Learning:** In desktop GUI apps, distraction-free modes often hide standard UI hints, making discoverability of keyboard shortcuts difficult. Adding hover tooltips to icon/action buttons provides an essential cognitive accessibility layer without cluttering the UI.
**Action:** Always check if secondary interaction modes (like full-screen or focus panels) lack the accessibility context provided in the main views, and add tooltips to expose hotkeys where appropriate.
